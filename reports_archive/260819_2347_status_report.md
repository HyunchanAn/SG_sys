# 세계화학공업(주) 통합 점착제 물성 예측 및 역설계 AI 시스템 전반 상태 보고서

## 1. 종합 개요 (Executive Summary)

현재 `SG_` prefix로 명명된 19개의 핵심 리포지토리(DB 포함)는 단순한 개별 스크립트의 집합을 넘어, **마이크로서비스 아키텍처(MSA) 기반의 완전한 통합 AI 파이프라인**으로 성공적으로 진화 및 고도화되었습니다. 기존에 혼재되어 있던 시스템 제어 로직, 데이터베이스, AI 추론 로직, 그리고 프론트엔드가 각각의 독립된 모듈로 분리되면서, 클린 아키텍처 원칙을 준수하는 강력한 솔루션이 완성되었습니다.

전체 시스템은 크게 **표면 인지(Vision) ➔ 조건 매칭(Matching) ➔ 배합 역설계(Inverse Design)**의 3단계 파이프라인으로 작동하며, 이를 중앙에서 조율하는 **오케스트레이터(`014`)**와 이를 시각적으로 표출하는 **관제 프론트엔드(`015`)**, 전체 런타임과 버전 동기화를 관장하는 **DevOps 인프라(`SG_sys`)** 및 **데이터 웨어하우스(`SG_DB`)**로 역할이 명확하게 배분되어 있습니다. 최근 통합 E2E 벤치마크 테스트 결과, 상호 통신 병목 없이 99.8%의 데이터 정합성을 유지하며 가동 중입니다.

## 2. 시스템 아키텍처 및 코어 인프라 현황

### 인프라스트럭처 그룹
*   **SG_sys (통합 DevOps 및 인프라스트럭처 제어 모듈)**
    *   **역할**: 전체 모듈을 총괄하는 Root 디렉토리. CI/CD 스크립트(`run_all_tests.sh`), 버전 일괄 동기화(`push_all.sh`), MSA 런타임(`docker-compose.yml`) 배포 등을 전담합니다.
    *   **상태**: 런타임 분리(Docker Bridge 통신) 및 공통 Pydantic 스키마 통합을 달성했습니다.
    *   **향후 방향**: 내부망 통신 시 보안성을 더 끌어올리기 위한 API Key 인증 체계 전환 확립이 요구됩니다.
*   **SG_DB (데이터 웨어하우스 스토리지)**
    *   **역할**: PostgreSQL DB 및 머신러닝 학습용 원본 비정형 데이터(Excel, IR, 랩 코팅 기록 등)를 영구 보존하는 스토리지. 
    *   **상태**: 004 모듈에서 물리적으로 분리되어 SSOT(Single Source of Truth) 원칙 하에 무결성 보장.
    *   **향후 방향**: 지속적으로 생성되는 실험/현장 데이터의 파이프라인 자동화(ETL) 스크립트 고도화.

### 파이프라인 그룹 (통합 스텝 서브모듈 래퍼)
*   **SG_integration_step1, 2, 3**
    *   **역할**: 복잡한 모듈들을 논리적인 파이프라인 단위(1단계: 계측, 2단계: 매칭, 3단계: 역설계)로 묶어 관리하는 Git Submodule 레포지토리.
    *   **상태**: 1.1버전 릴리즈 등 각 파이프라인별 E2E 동작 성공적 검증.

## 3. 개별 모듈별 세부 현황 및 나아가야 할 방향

전체 마이크로서비스 모듈(`SG_proj_001` ~ `015`)의 현재 상태와 세부 과제입니다.

### 🔴 Step 1: 표면 인지 및 분석 (Vision & Physics)
1.  **SG_proj_002 (DeepDrop-AnyView)**
    *   **상태**: SAM 2.1 및 GFN2-xTB 물리 모델을 적용, 원근 왜곡 보정 및 표면 자유 에너지(SFE) 산출 완성.
    *   **방향**: 다양한 환경 조명에 대한 엣지 검출 Robustness 향상.
2.  **SG_proj_003 (V-SAMS)**
    *   **상태**: 동전 반사상을 기반으로 가변 블러링 적용, 조도 및 마감 상태 판별 완료.
    *   **방향**: 종합 플랫폼의 서브 엔진 병합 진행, 노이즈 필터 가속화(MPS/CUDA VRAM 해제 최적화 유지).
3.  **SG_proj_007 (SG-TERRA)**
    *   **상태**: 단안 이미지에서 3D 지형도 복원, 평균/가우시안 곡률 도출 및 SFE 모바일 친화적 인터페이스 구축.
    *   **방향**: Depth-V2와 SAM2 동시 추론 시의 Latency 병목 해소를 위해 TensorRT 또는 ONNX 경량화 추가 탐색.
4.  **SG_proj_010 (금속 재질 및 마감 판별)**
    *   **상태**: EfficientNet-V2를 통해 다중 태스크(재질, 마감유형) 인지 API 운영.
    *   **방향**: 신규 피착재(플라스틱 계열 등) 추가 도메인 확장을 위한 지속적 파인튜닝 로직 마련.
5.  **SG_proj_011 (필요 가공성 판별)**
    *   **상태**: 007 데이터와 재질 강성 기반 가공 레벨 1~5 평가.
    *   **방향**: 예외 상황(강판 크랙 등)에 대한 정교한 물리적 Fallback 분기 추가 설계.

### 🟣 Step 2: 제품 매칭 및 중앙 오케스트레이션
1.  **SG_proj_004 (제품 및 피착재 DB MSA Gateway)**
    *   **상태**: 기존 단일 Monolithic 코드에서 벗어나 SG_DB를 연결하는 전담 REST API 서버로 승격. SQLAlchemy 적용.
    *   **방향**: 대량 트래픽 쿼리를 대비한 Redis 캐싱 레이어 도입 검토.
2.  **SG_proj_012 (제품 DB 매칭 엔진)**
    *   **상태**: Reference-Bounds TOPSIS 기반 다기준 추천, 오프라인 가중치 옵티마이저 구동.
    *   **방향**: 사용자 피드백(실제 현장 선택 결과) 기반 가중치 동적 업데이트(Online Learning) 강화.
3.  **SG_proj_014 (관제탑 오케스트레이터 서버)**
    *   **상태**: 001~013 전체의 E2E 제어 흐름 분배, Pydantic v2 기반 도메인 한계 검증, 422 커스텀 핸들링, 비례제어 피드백(Proportional Control) 완수.
    *   **방향**: 시스템 병렬 처리(동기/비동기 혼합) 완전 비동기화 달성 및 헬스체크(Circuit Breaker) 아키텍처 확립.

### 🟢 Step 3: 수지 역설계 및 분자 모사 (Inverse Design)
1.  **SG_proj_013 (역설계 검증 및 메타 모델 게이트웨이)**
    *   **상태**: 001, 006, 009 모듈을 엮어 최적화 배합의 물리/화학적 성질을 반복 검증.
    *   **방향**: **[최우선 과제]** 가장 유사한 기성품의 베이스를 최대한 유지하면서 일부 비율만 미세 조정(Base-Modification)하도록 "기성품 기반 유사도(Cosine) 페널티"를 검증에 추가하여 현업 친화적(Production-ready)인 레시피 창출 보장.
2.  **SG_proj_001 (물성 예측 엔진 V2)**
    *   **상태**: XGBoost/NSGA-II 최적화 기반, 동적 상한선(Bounds) ও 분리형 희소성 제약을 통해 Data Leakage 원천 차단된 강건한 역설계 모델 완성 (Adhesion R2 0.738).
    *   **방향**: 궁극적으로 현재의 진화 연산 탐색법을 넘어 PyTorch 기반 CVAE 다이렉트 딥러닝 역설계 엔진 도입 연구.
3.  **SG_proj_006 (TransPolymer)**
    *   **상태**: SMILES 기반 물리 속성(Tg, FFV, 열전도도 등) 예측 멀티태스크 튜닝 완료.
    *   **방향**: 점착제 도메인(아크릴계)에 특화된 극소량 첨가물 영향력 감지력 강화를 위한 대용량 추가 학습 벤치마크.
4.  **SG_proj_009 (IR 시뮬레이터)**
    *   **상태**: GNN 및 GFN2-xTB 기반 IR 스펙트럼 생성, 역예측(Bayesian).
    *   **방향**: 양자 역학 시뮬레이션의 연산 병목을 해소하기 위한 사전 구축 피쳐(Cache) 시스템 마련.

### 🟡 품질 검증(QC) 및 독립 구동 모듈
1.  **SG_proj_005 (표면 이상 탐지)**
    *   **상태**: PatchCore(Anomalib) + SAM2 분할 이상 탐지.
    *   **방향**: 기존 파이프라인 외부 모듈이나, 향후 014 오케스트레이터 1단계(Vision)에 병합하여 결함 발생 강판 사전 블로킹 로직 구현.
2.  **SG_proj_008 (제품 유지력 정량화)**

    *   **방향**: 시간 종속적 가중치 스코어를 머신러닝/지수평활법으로 더욱 고도화하여 내구성 예측 정밀도 상승 유도.

### 🌐 프론트엔드 그룹

    *   **방향**: E2E 시뮬레이션 실시간 로그 렌더링, WebSockets 등을 통한 비동기 상태 진행바 UX 고도화.

## 4. 전반적인 향후 발전 방향 요약 (System Masterplan)

1. **Security & Authentication (보안 및 인증 체계 강화)**: Trusted Network 기반으로 동작하는 각 컨테이너 통신망을 API Key 혹은 OAuth 인프라로 격상하여 기업 보안 규격을 달성해야 합니다.
2. **Production-Ready Inverse Design (현장 중심의 역설계 산출물 보장)**: 단순 스펙 맞추기 식 배합이 아니라, 공장에서 보유 중인 기성 원자재와 양산 경험을 존중하는 "유사도 페널티"(`SG_proj_013`) 로직의 도입이 가장 시급한 개발 타겟입니다.
3. **Deep Generative Inverse Model (생성형 AI 심층 도입)**: NSGA-II(진화 연산) 탐색은 안정적이나 한계가 있습니다. 배합을 직접 생성하는 CVAE 아키텍처(`SG_proj_001` 하위 브랜치) 적용을 가속화해야 합니다.
4. **Latency Zero (응답 병목 타파)**: Vision 딥러닝 3종(002, 003, 007) 모듈의 병렬 호출 시 VRAM OOM 관리 및 ONNX/TensorRT 변환을 통해 전체 응답 속도를 2초대(역설계 포함 시 5초대)로 안정화하는 인프라 최적화가 필수적입니다.
