# [보고서 및 계획서] 역설계 모듈(NSGA-II) 최적화 튜닝 플랜

## 1. 테스트 결과 요약 (현상 파악)
- **목표 (Target)**: 점착력 400, Tg -30도, 점도 2500
- **도출 결과 (Result)**: 점착력 258, Tg -9.5, 점도 20.0
- **진단**: E2E 파이프라인 인프라는 정상 동작하지만, NSGA-II 유전 알고리즘이 목표 공간(Latent Space)을 제대로 탐색하지 못하고 심각한 로컬 미니마(Local Minima)에 빠져 탈출하지 못하고 있습니다.

## 2. 수학적/알고리즘적 근본 원인 분석

엔진 내부(`engine.py`) 분석 결과, 다음과 같은 심각한 수학적 결함 두 가지를 발견했습니다.

### A. 하드 마스킹(Hard Masking)으로 인한 유전 탐색 단절
현재 코드는 `enforce_separated_sparsity` 함수를 통해 강제로 상위 4개의 모노머만 남기고 나머지를 0.0으로 덮어씌웁니다. 
유전 알고리즘(NSGA-II)은 미세한 돌연변이(Mutation)를 통해 점진적으로 진화해야 하는데, 함수 내부에서 강제로 0으로 잘라버리면 기울기(Gradient)와 진화의 방향성이 상실됩니다. 알고리즘은 자신이 어느 방향으로 나아가야 할지 시야가 차단된 채 무작위로 방황하다가 초기 세대에서 수렴해버립니다.

### B. 목적 함수(Objective Function)의 스케일 붕괴
현재 NSGA-II 목적 함수는 단순히 `abs(예측값 - 목표값)`을 사용합니다.
- 점도(Viscosity)는 단위가 1000~5000대입니다.
- Tg는 단위가 -10 ~ -50대입니다.
이 상태로 단순 뺄셈 오차를 사용하면 알고리즘은 1000 단위인 '점도' 오차를 줄이는 데에만 모든 연산력을 쏟아붓고, 정작 가장 중요한 Tg나 점착력은 무시해버리는 **스케일 지배(Scale Domination)** 현상이 일어납니다. 

## 3. 리팩토링 구현 계획 (Implementation Plan)

### Phase 1: 스케일 정규화 (Normalization) 도입
각 타겟 속성의 오차를 단순 절댓값이 아닌 **백분율 오차(Percentage Error) 또는 스케일 정규화(Standardization)** 방식으로 변경하여, 모든 물성치가 동등한 가중치로 최적화되도록 밸런스를 교정합니다.
```python
# AS-IS
f.append(abs(pred_val - target_val))
# TO-BE
f.append(abs(pred_val - target_val) / (abs(target_val) + 1e-5))
```

### Phase 2: 희소성(Sparsity) 제약의 소프트화
강제 하드 마스킹(0.0 할당)을 제거하고, 모노머 개수 자체가 하나의 최적화 지표가 되도록 **소프트 패널티(Soft Penalty)** 혹은 아예 NSGA-II의 **추가 목적 함수(Objective)**로 분리합니다.
이를 통해 "물성은 훌륭하지만 성분이 6개인 레시피"와 "물성은 약간 타협했지만 성분이 4개인 레시피" 간의 진정한 파레토 프론트(Pareto Front)를 도출해낼 수 있습니다.

### Phase 3: 도메인 패널티 가중치 리스케일링
겔화 방지(AA, 2-HEMA 상한) 등의 물리적 제약 조건(Constraints)이 진화 과정에서 너무 일찍 해로(Feasible Space)를 닫아버리지 않도록, 제약 조건 평가기(`DomainPenaltyValidator`)의 허용치를 완만하게 수정합니다.
