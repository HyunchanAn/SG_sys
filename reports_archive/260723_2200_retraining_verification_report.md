# 모델 재학습 및 데이터 누수 해결 결과 보고서

## 1. 개요
* **작업 일시**: 2026-07-23
* **수행 내용**: `SG_proj_001` 모듈 내 통합 학습 스크립트(`train_unified_optimized_models.py`)의 데이터 누수(Data Leakage) 원인 제거 및 RTX 5080 GPU 가속 환경에서의 모델 강제 재학습 수행.

## 2. 데이터 누수(Data Leakage) 해결
* **원인 분석**: 기존 모델 학습 시 입력 피처(X)에 타겟 변수(`syn_viscosity_cp`, `syn_tg`)가 포함된 채로 학습되었습니다. 이로 인해 모델이 입력 조건(Monomer 비율, 온도 등)이 아닌 타겟 변수 자체를 정답지로 인식하여 학습하는 치명적인 오류가 발생했습니다.
* **해결 방안**: 
  - 학습 전 피처 선정 단계(`syn_exclude` 리스트)에 타겟 변수의 영문 컬럼명(`syn_viscosity_cp`, `syn_tg`)을 명시적으로 추가하여 훈련 세트에서 배제했습니다.
  - 학습 실행 전 `assert` 구문을 추가하여 `test_점착력` 및 타겟 변수들이 피처 리스트에 포함될 경우 훈련이 즉시 중단되도록 안전장치를 마련했습니다.

## 3. 재학습 및 검증 결과
수정된 스크립트를 통해 총 7,119건의 데이터를 바탕으로 50차원(Unified Global Dimension)으로 정제한 후 모델을 성공적으로 학습했습니다.

* **Tg (유리전이온도) 예측 모델**: R2 Score `0.8880`
* **점도 (Viscosity, cP) 예측 모델**: R2 Score `0.7289`
* **점착력 (Adhesion) 예측 모델**: R2 Score `0.1778` (추가 데이터 및 피처 엔지니어링 필요)

### 성과 및 시사점
과거 점도 예측 모델의 R2 Score가 `0.9999`로 나타났던 것은 학습이 잘 된 것이 아니라 **데이터 누수에 의한 과적합(Overfitting/Cheating)** 때문이었습니다.
정상적으로 물리적 제약조건을 기반으로 학습한 결과, 점도 예측 성능은 현실적인 수치(`0.7289`)로 회귀하였으며, 이제 모델은 단순히 20 cP와 같은 상수 값을 뱉어내는 대신 Monomer 비율과 환경 변수에 따라 **동적인 물리량**을 추론할 수 있게 되었습니다.

## 4. 향후 계획 (Next Steps)
1. **모델 배포 및 연동**: 로컬 폴더(`.pkl`)에 저장된 새로운 모델들을 ONNX 포맷으로 변환한 뒤, 기존 추론 엔진(`sg_polysim.engine`)이 로컬 모델을 우선적으로 참조하거나 Hugging Face 리포지토리를 업데이트하도록 파이프라인 개편.
2. **점착력 예측 모델 고도화**: 현재 점착력 예측 정확도가 낮으므로, 기재(Substrate)의 표면 에너지 및 조도 등 물리 화학적 메타 데이터를 보강하여 성능 향상 도모.
3. **Monomer 조합 최적화 엔진(NSGA-II) 적용**: 정상화된 예측 모델을 바탕으로 버그가 픽스된 탐색 알고리즘을 실무 레시피 추천 시스템에 본격 도입.

### 💡 점착력 예측 모델 성능 저하 원인 분석 (추가 코멘트)
현재 점착력 예측 모델의 R2 Score가 **0.1778**로 다소 아쉽게 나온 이유는 모델 학습 피처에 물리적 '외부 변수'가 배제되어 있기 때문입니다. 

1. **피착재(Substrate)의 단일성 및 한계**
   데이터의 절대다수가 SUS BA(Bright Annealed) 표면 등 특정 기재에서 측정된 박리력(Peel Adhesion)에 편중되어 있습니다. 점착력은 고분자 자체의 벌크 성질이 아닌 '계면 물리량'이므로, 다양한 피착재 조건에 대한 피처가 부족할 경우 예측 한계가 존재합니다.
2. **점착력을 결정하는 물리적 '외부 변수' 배제 (치명적 원인)**
   현재 `SG_proj_001` 엔진은 "고분자 중합 레시피(모노머 비율)"만을 입력받습니다. Tg나 점도는 벌크 물성이라 모노머 비율만으로 예측 가능하지만, 점착력은 **코팅 두께(도포량)**와 **경화제(Crosslinker) 투입량**에 따라 동일 배합에서도 2~3배 요동칩니다. 현재 모델은 이 핵심 물리 조건들을 모두 가린 상태에서 오직 화학 배합표만 보고 점착력을 추론하려 하기 때문에 노이즈로 인식되어 R2 점수가 낮을 수밖에 없습니다.
